# Local Voice Studio V2

Local Voice Studio V2 (LVSV2) helps you record and organize voice clips, prepare a dataset for training, and manage trained voice models.

To create a voice model, record clean speech from a voice you own or have permission to use, then train the recordings with RVC WebUI. Around 10 minutes of varied, clear speech is a useful starting point, but the results depend on the recordings, training settings, and computer.

LVSV2 does not train or change voices by itself. For live voice changing in apps such as Discord, you also need a compatible live voice converter. You choose the trained model and audio devices in that converter.

## Why is there no V1?

The first version did not work reliably, so it was replaced with a rebuilt version: Local Voice Studio V2. V2 is the version this project focuses on.
